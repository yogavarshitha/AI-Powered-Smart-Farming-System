# 🌾 AI-Powered Smart Farming System

## 🧠 Project Overview
The **AI-Powered Smart Farming System** is a web-based application designed to assist farmers in making data-driven decisions.  
It uses Artificial Intelligence to recommend crops, detect plant diseases, suggest fertilizers, and manage irrigation — all in one platform.

---

## 🌱 Key Features
- **Crop Recommendation:** Suggests the best crops based on soil and climate data.  
- **Disease Detection:** Uses a CNN model to identify plant diseases from leaf images.  
- **Fertilizer Suggestion:** Recommends suitable fertilizers based on soil health.  
- **Smart Irrigation:** Controls water supply based on soil moisture and weather conditions.  
- **Market Insights:** Displays nearby cold storage and real-time market prices.  

---

## 🧩 Tech Stack
- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Python (Flask Framework)  
- **Database:** SQLite  
- **Machine Learning Models:** CNN, Random Forest, Regression Models
